# Shining Auto News Bot v1.3

Готовий безкоштовний автопостинг важливих новин російською в Telegram через GitHub Actions + Gemini API + RSS + Binance.

## Що робить
- Перевіряє новини та BTC/ETH/SOL кожні 30 хвилин (розклад GitHub може затримуватися).
- Постить російською тільки перевірені важливі новини, від 75/100.
- Публікує до 5 звичайних новин за київську добу; оцінка 90+ не входить у цей ліміт.
- З 23:00 до 08:00 за Києвом надсилає повідомлення без звуку, крім надзвичайних новин 98+ і особливо сильних рухів ринку.
- Окремо перевіряє ±5% за 1 годину та ±5% за останні 24 години для BTC/ETH/SOL за публічними даними Binance Spot. Період є в кожному алерті. Пороги, повторний алерт і терміновість налаштовуються для кожної монети та періоду.
- Не публікує звичайні новини без офіційного першоджерела або двох незалежних висвітлень (автоматична перевірка НЕ є гарантією істини).
- Чергує статті різних видавців у запиті до Gemini, щоб наприкінці списку не домінувала NASA. Дрібні анонси NASA без незалежного підтвердження впливу пропускає.
- Зберігає історію, запобігає повторам і записує причини пропусків та помилки в логи.
- Надсилає пости без карток попереднього перегляду; джерела показує як клікабельні назви без довгих URL у тексті.
- У середньому 70% звичайних новин мають короткий рекламний підпис із клікабельним FINDOLLAR. Для 80% таких підписів Gemini пропонує фразу під тему новини; якщо вона не підходить, бот використовує перевірений шаблон. Під трагедіями та надзвичайними новинами реклами немає. Ринкові алерти її теж не отримують.
- Додає одне фото з цитованого джерела, якщо RSS явно вказує для цього фото CC0, Public Domain Mark або CC BY 3.0/4.0 з автором. У підписі є атрибуція й посилання на ліцензію. За відсутності підтверджених прав або якщо Telegram не завантажить фото, публікує текст без зображення.
- За замовчуванням **публікацію вимкнено**, поки явно не створите змінну `PUBLISH_ENABLED=true`.

## Покрокове встановлення

### 1. Telegram
1. Відкрийте https://t.me/BotFather.
2. Надішліть `/newbot`; задайте ім'я та username (username повинен закінчуватися на `bot`).
3. Отримайте **bot token**. Нікому не надсилайте його та не вставляйте у відкриті файли.
4. Створіть **публічний** Telegram-канал з username, наприклад `@my_news_channel`.
5. Додайте бота до адміністраторів каналу й увімкніть право **публікувати повідомлення**.
6. Запишіть username каналу з `@` як `TELEGRAM_CHAT_ID`.

### 2. Gemini API
1. Відкрийте https://aistudio.google.com/api-keys і ввійдіть у свій Google-акаунт.
2. Створіть ключ **Gemini API** у проєкті Free Tier, якщо доступний.
3. **Не активуйте платний billing**, якщо потрібно суворо 0 грн.
4. Збережіть ключ як `GEMINI_API_KEY`.

Підписка Gemini в застосунку **не означає** оплачені API-запити. Безкоштовний API діє в межах лімітів; якщо квота недоступна чи вичерпана, новини не публікуються, а BTC-алерти можуть працювати окремо.

### 3. GitHub
1. Відкрийте https://github.com/new, увійдіть або зареєструйтеся.
2. Створіть новий **Public** репозиторій, наприклад `telegram-ai-news-radar`.
3. Розпакуйте архів і завантажте всі файли через **Add file → Upload files**. Не забудьте приховану папку `.github/workflows/` з файлом `radar.yml`! Якщо GitHub вебінтерфейс не додає приховану папку, створіть файл вручну **Create new file** з іменем `.github/workflows/radar.yml` та скопіюйте його вміст.
4. Відкрийте **Settings → Secrets and variables → Actions → Secrets**.
5. Створіть **три repository secrets**:
   - `GEMINI_API_KEY` = ваш API-ключ Gemini;
   - `TELEGRAM_BOT_TOKEN` = токен від BotFather;
   - `TELEGRAM_CHAT_ID` = username публічного каналу, наприклад `@my_news_channel`.
6. Перейдіть у **Settings → Secrets and variables → Actions → Variables**.
7. Створіть repository variable `PUBLISH_ENABLED` зі значенням `false`.
8. Переконайтеся, що GitHub Actions мають дозвіл робити коміти в репозиторій: **Settings → Actions → General → Workflow permissions → Read and write permissions → Save**, якщо такий контроль доступний.

### 4. Тест (без публікації)
1. Перейдіть **Actions → Shining Auto News Bot → Run workflow**.
2. Залиште режим **test** і натисніть **Run workflow**.
3. Перевірте логи кроків «Verify radar logic without publishing» та «Run news radar». Потенційні публікації матимуть префікс `[TEST]`.
4. Якщо є `HTTP 403` від Gemini, перевірте дозволені регіони/моделі, Free Tier і API-ключ.
5. Якщо немає цікавих новин, `[TEST]` може не з'явитися. Це нормально; дивіться, чи читаються RSS і Binance.

### 5. Запуск повного автомата
1. У **Settings → Secrets and variables → Actions → Variables** змініть `PUBLISH_ENABLED` на `true`.
2. За бажанням натисніть **Actions → ... → Run workflow → live**, щоб перевірити негайно, або дочекайтеся наступного розкладу.
3. Тепер GitHub запускає сканер щопівгодини сам; комп'ютер і телефон можуть бути вимкнені.
4. Щоб призупинити публікації, поверніть `PUBLISH_ENABLED=false`.

## Де змінювати параметри
- `config.json`: `importance_threshold` (75), `market_alerts` (окремі пороги 1h/24h, cooldown та межа терміновості), `max_posts_per_run` (3), Gemini model, RSS sources.
- `.github/workflows/radar.yml`: `cron: '11,41 * * * *'` означає кожні 30 хвилин за UTC, з можливими затримками GitHub.
- `state.json`: історія публікацій, кеш новин і стан алертів. **Не редагуйте вручну**, якщо все працює.

## Керування в Telegram

Команди передаються Telegram прямо у Vercel через захищений webhook і не чекають розкладу GitHub. Налаштування зберігаються у приватному Blob та синхронізуються перед живими запусками радара. Докладніше: `ops/WEBHOOK.md`.

1. Напишіть боту в **особисті повідомлення** `/settings` або `/menu` з одного з двох дозволених акаунтів. Головний екран показує поточний стан. Розділи «Новини», «Рекламний підпис» і «Цінові алерти» мають кнопки вибору, позначку ✅ біля поточного значення та підтвердження збереження.
2. Кнопка «Своє значення» або «Змінити мій текст» просить звичайне наступне повідомлення. Введення діє 15 хвилин, має кнопку скасування й окреме для кожного адміністратора. Старі slash-команди також підтримуються.
3. Якщо треба перевірити власний числовий Telegram ID, напишіть `/id`.

Доступ до налаштувань мають лише два дозволені ID і лише з приватного чату. У публічному `config.json` записано їхні SHA-256 хеші. Команда `/id` повідомляє будь-якому користувачеві тільки його власний ID. Токен із GitHub Secrets передано у Vercel у зашифрованому вигляді; ключ розшифрування є тільки в середовищі окремого webhook-проєкту.

Приклади: `/brand auto`, `/brandtext 💚 Рынок меняется. Следи за своими финансами вместе с FINDOLLAR`, `/limit 5`, `/gap 60`, `/market ETH 24h 6`. `/limit 0` призупиняє звичайні новини, але пропускає важливі 90+. `/news off` вимикає всі новини, не зачіпаючи BTC/ETH/SOL.

## Обмеження / безпека
- GitHub Actions у публічних репозиторіях безкоштовні для стандартних runner-ів, але GitHub може затримати або пропустити окремі запуски. У публічному репозиторії **scheduled workflows можуть автоматично вимикатись після 60 днів неактивності**. Не можна обіцяти абсолютний 24/7 без догляду.
- Публічний репозиторій відкриває код та `state.json`, тому не зберігайте там приватні дані. Секрети є тільки в GitHub Secrets і середовищі Vercel, а не відкритим текстом у коді.
- Gemini Free Tier має обмеження, може бути недоступний у певному регіоні або змінюватися. **Не підключайте billing**, якщо принципово не хочете платити.
- Алгоритм не може гарантувати, що жодна хибна новина не пройде: два видання іноді повторюють помилку один одного. Для репутаційно важливого каналу бажано перевірити його на тестовому каналі хоча б кілька днів.
- Бот **не копіює статті повністю**. Пише короткі самостійні підсумки з посиланнями на джерела; перевіряйте умови RSS видавців.
- Саме посилання на статтю не дає дозволу передруковувати її фото. Більшість редакційних RSS не містить окремої ліцензії для зображення, тому текстові пости залишаться звичайним явищем.
- Якщо Gemini API не працює, новини пропускаються без фейкової публікації.

## Технології
Радар використовує стандартну бібліотеку Python. Webhook використовує FastAPI, cryptography та офіційний Vercel Blob SDK. Додаткові платні плани не підключаються; діють ліміти наявного тарифу Vercel.
